一、功能流程完整度

本轮覆盖生产环境放款前主路径：注册 → 填资 → 白名单授信 → 借款页。流程完整，无卡点。

注册登录→ 填资 KYC→ 授信（白名单）→ 借款页（放款前）
  • 真实设备、真实生产环境走完放款前链路
  • Backend 人审 / 用户信息等关键路径一并过到
  • 职场同事现场参与，账号可直接用于二轮

本轮边界为放款前；放款 → 还款等放二轮（短信渠道 / 支付渠道就绪后启动）。

二、用户体验

主流程体验可走通。试单中顺手记了一些可打磨点，已和研发推进一部分，其余提审前继续一起优化。

本轮已推进

  • 隐私勾选提示更清晰；
  • TIN / 驾照等证件正则校验对齐并优化；企业邮箱可正常收验证码
  • 借款协议静态资源发菲律宾节点
  • 增信人审规则、人脸比对配置等与相关同学对齐并落地

继续打磨

  • 填资键盘遮挡、邮箱布局与错误提示、OTP 等待反馈
  • 证件提示文案与正则口径一致性；
  • 弱网下图片 / 合同加载体感；安装包体积评估

完整条目见文档【生产试单checklist】。
